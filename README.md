# Angela Gadzhieva — Personal Trainer

Одностраничный сайт-визитка персонального тренера Анжелы Гаджиевой.

## Структура
- Главный экран
- Система тренировок + видео
- Цели
- Обо мне
- Форматы тренировок и стоимость
- До / После
- Сопровождение по питанию
- Контакты и WhatsApp

## Запуск
Сайт статический и не требует сборки. После загрузки папки `assets` можно публиковать через GitHub Pages из ветки `main`.
